# Diagramas do repositório claude-code-mods-gbvdm

Diagramas de sequência do processo do repositório. Abra na pré-visualização do VS Code (`Ctrl+Shift+V`). Os diagramas da lógica do painel ficam em `plugins/painel-sessao/.diagramas.md`.

---

## 1. Da alteração à publicação: três lugares e dois portões

> **De onde:** `CONTRIBUTING.md` (o processo escrito), `scripts/check.mjs` (valida o catálogo e cada plugin, roda os testes e confere que todo texto em português tem versão em inglês) e `scripts/release.mjs` (aumenta o número de versão em `plugin.json`, data a seção `Unreleased` do `CHANGELOG.md`, cria o commit e a tag na `main`; não envia ao GitHub).<br>
> **Conferido em 14/10/2026:** os dois scripts rodaram numa cópia descartável do repositório (versão 0.2.0 passou a 0.2.1, com a tag `painel-sessao--v0.2.1`; um texto sem versão em inglês fez a verificação falhar). **Não conferido:** se uma sessão já aberta recarrega o painel sozinha quando a `main` muda. Sessão nova carrega a versão da `main`.

```mermaid
sequenceDiagram
    autonumber
    actor G as Guilherme
    participant C as Claude (sessão de desenvolvimento)
    participant W as Worktree claude-code-mods-gbvdm-dev (branch)
    participant M as main local (C:\Repos\claude-code-mods-gbvdm)
    participant S as Sessões do Guilherme
    participant H as GitHub (catálogo gbvdm-mods)
    actor U as Outros usuários

    rect rgba(138, 180, 248, 0.12)
    Note over G,U: Lugar 1: a alteração é escrita onde nenhuma sessão carrega
    G->>C: Pede uma alteração no painel
    C->>W: Altera o código e adiciona a linha em CHANGELOG.md, seção Unreleased
    C->>W: Roda node scripts/check.mjs
    W-->>C: Retorna validação, testes e textos em inglês
    end

    rect rgba(129, 201, 149, 0.12)
    Note over G,U: Portão 1: só entra na main o que passou na verificação
    C->>M: git merge --ff-only da branch
    M-->>S: Sessão nova carrega a versão da main (CLAUDE_CODE_PLUGIN_DIRS aponta para plugins/painel-sessao)
    G->>S: Confere a alteração na tela
    alt a alteração tem defeito
        G->>C: Pede para desfazer
        C->>M: git reset --hard para o commit anterior
    end
    end

    rect rgba(253, 214, 99, 0.12)
    Note over G,U: Portão 2: só vai ao GitHub uma versão nova, com a aprovação do Guilherme
    C->>M: node scripts/release.mjs patch, minor ou major
    M-->>C: Retorna o commit "release" e a tag painel-sessao--v(versão)
    C->>G: Pede aprovação do envio
    G->>C: Aprova
    C->>H: git push origin main --follow-tags
    U->>H: claude plugin update painel-sessao@gbvdm-mods (ou atualização automática do catálogo)
    H-->>U: Envia a cópia nova, porque o número de versão mudou
    end
```

**Limites que o diagrama não mostra:**

- Um envio ao GitHub sem número de versão novo não chega a ninguém: o Claude Code de quem instalou guarda a cópia que tem até o número mudar.
- O notebook está fora do processo por decisão do Guilherme (14/10/2026). Como o `settings.json` sincroniza, lá o `CLAUDE_CODE_PLUGIN_DIRS` aponta para uma pasta que não existe, e o painel não carrega.
